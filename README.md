Personal learning repository for the C programming language, built while
studying **Systems Development Technician** at IFSULDEMINAS.

This repo documents my progress chapter by chapter, from the basics up to
Arrays, combining C fundamentals with practical exercises focused on
**Healthcare/Nursing** (my other field of study — Nursing at UFRA), plus
Applied Math and a bit of IoT as complexity grows.

Bilingual approach: explanations happen in Portuguese during my study
sessions, but all code (variable names, comments, function names) and
documentation (notes/) are written in English — a way to practice
technical English alongside C itself.

## 📁 Structure

```
c-healthcare-learning/
├── exercises/      # Chapter-by-chapter guided exercises
│   ├── chapter01/
│   ├── chapter02/
│   └── ...
├── ideas/          # Extra practice exercises (health, math, IoT themes)
├── include/        # Shared header files (used from later chapters on)
├── notes/          # Theory notes per chapter (.md)
└── projects/       # Larger, multi-file integrated projects
```
